# eVocalrankScoreUtil

## 1. 简介

本仓库记录了[虚拟歌手中文曲排行榜](https://www.evocalrank.com/)从2025-1-11开始的的分数计算公式
本仓库将记录以后每次公式更新，并同步在本仓库内

## 2. 用法
1. clone本仓库
2. 找到最新的公式脚本(YYYY-mm-dd.py)
3. 把他复制到你的项目内，直接调用`get_final_score()`函数，返回此稿件的周刊得分

## 3. 参数说明
 `原始XX增量` 本周本数据的增长总量
 
## 4. 鸣谢
[虚拟歌手中文曲排行榜](https://www.evocalrank.com/) 对中文Vocaloid社区的贡献，以及公式来源
